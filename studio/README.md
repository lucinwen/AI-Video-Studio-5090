# 创作者工作台

`studio/` 是本仓库的创作者界面，与 Windows 部署脚本一起维护。当前是无需依赖的本地网页预览，不是已接入 GPU 的生成工作台。

## 预览
在支持 HTML5 的浏览器中打开 `index.html`。可创建项目、添加镜头、编辑并保存镜头卡、导入本机 MP4 审片。镜头卡使用浏览器本地存储（如浏览器允许）；视频文件不会上传，也不会随页面刷新保留。此版未调用 ComfyUI。
